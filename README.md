# java-racingcar-precourse

## 미션 개요
쉼표(,)로 구분된 자동차 이름과 시도 횟수를 입력받아, 각 라운드마다 무작위 값(0~9)으로 전진 여부를 결정합니다. 전진 조건(값 ≥ 4)을 만족한 자동차는 `-` 한 칸 전진하며, 모든 라운드가 끝나면 가장 많이 전진한 자동차(복수 가능)를 우승자로 출력합니다.

## 입출력 형식
- 안내 문구
    - `경주할 자동차 이름을 입력하세요.(이름은 쉼표(,) 기준으로 구분)`
    - `시도할 횟수는 몇 회인가요?`
- 라운드 출력
    - 각 라운드에서 자동차별 상태 한 줄씩: `이름 : ---`
    - 라운드가 끝나면 빈 줄 한 줄 출력
- 최종 결과
    - `최종 우승자 : pobi, jun` (복수 우승자는 쉼표+공백으로 구분)

## 구현할 기능 목록
- [ ] 자동차 이름 검증
    - [ ] 이름은 공백/빈 값 불가
    - [ ] 이름 길이는 1~5자
- [ ] 시도 횟수 입력 검증
    - [ ] 정수만 입력 가능
    - [ ] 1 이상 값
- [ ] 라운드 진행
    - [ ] 각 자동차에 대해 무작위 수(0~9) 생성
    - [ ] 전진 조건: 값 ≥ 4면 전진
- [ ] 라운드 출력
    - [ ] `이름 : ---` 형식으로 출력
    - [ ] 라운드 종료 후 빈 줄 출력
- [ ] 최종 우승자 계산
    - [ ] 최댓값 위치를 가진 자동차(복수 가능) 추출
    - [ ] `최종 우승자 : a, b` 출력
- [ ] 예외 처리
    - [ ] 잘못된 입력 시 `IllegalArgumentException` 던지기
    - [ ] `Application.main`에서 메시지만 출력 후 종료 (`System.exit()` 금지)
